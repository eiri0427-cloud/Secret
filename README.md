# 舊案重啟：雙人推理檔案

給兩個人用手機遠距合作的推理遊戲。兩人各拿一半的卷宗，開著通話，用說的交換線索，一起破案。

- 第 01 案《最後一場》：2005 南星大戲院命案（約 2 小時）
- 第 02 案《雪線以上》：2011 雲杉山莊凍死事件（約 2.5–3 小時）
- 第 03 案《末班車之後》：1997 霧溪站女教師失蹤案（約 2.5–3 小時）

所有人物、地點、事件皆為虛構。

## 怎麼玩

1. 兩人各自打開網頁，選同一個案件，一人當「證詞組」，一人當「鑑識組」。
2. 只能用說的描述自己看到的文件，不要截圖。
3. 合力算出每一章的密碼，解鎖下一批卷宗。
4. 到「偵訊」把文件出示給關係人。問出新證詞的人會拿到四位數代碼，念給夥伴輸入。
5. 結案報告全對後，還有最後一場對質。

一個人也可以玩：選「單人模式」。

進度存在各自手機的瀏覽器裡，換瀏覽器或清除資料就會消失。

## 放上 GitHub Pages

1. 在 GitHub 建一個新的 repository，把這個資料夾裡的所有檔案上傳到根目錄。
2. 到 repository 的 Settings → Pages。
3. Source 選 Deploy from a branch，Branch 選 `main`、資料夾選 `/ (root)`，按 Save。
4. 等一兩分鐘，網址會是 `https://<你的帳號>.github.io/<repository 名稱>/`。

只需要 `index.html` 就能運作，它是單一檔案，沒有其他相依檔。

## 這個版本沒有即時同步

即時同步（一人解鎖、兩邊一起前進）依賴 Claude 的頁面功能，在 GitHub Pages 上不會啟動。遊戲會自動改用四位數代碼交換偵訊紀錄，密碼則是兩人各自輸入。其餘內容完全相同。

## 劇透警告

`src/` 資料夾裡有每個案件的完整答案和結局，是明文。`index.html` 裡的答案有做雜湊和編碼，一般遊玩不會看到，但不是加密。

如果不想讓玩家在 repository 裡翻到答案，就只上傳 `index.html`、`.nojekyll` 和這份 README，不要上傳 `src/`。

## 修改內容

需要 Node.js，不需要安裝任何套件。

```
node src/build.js
```

會重新產生根目錄的 `index.html`。

| 檔案 | 內容 |
|---|---|
| `src/template.html` | 介面與遊戲引擎 |
| `src/case1.js`、`case2.js`、`case3.js` | 各案件的文件、密碼、偵訊、結局 |
| `src/case1-docs.html` | 第 01 案的原始文件（由 `case1.js` 讀取） |
| `src/helpers.js` | 文件排版用的小函式 |
| `src/build.js` | 把以上合成 `index.html` |

要新增案件：照 `case2.js` 的格式寫一個新檔，加進 `build.js` 開頭的清單。
