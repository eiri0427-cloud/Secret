# 舊案重啟：雙人推理檔案

給兩個人用手機遠距合作的推理遊戲。兩人各拿一半的卷宗，開著通話，用說的交換線索，一起破案。

- 第 01 案《最後一場》：2005 南星大戲院命案
- 第 02 案《雪線以上》：2011 雲杉山莊凍死事件
- 第 03 案《末班車之後》：1997 霧溪站女教師失蹤案

每案四章，約 2.5–3 小時。所有人物、地點、事件皆為虛構。

## 怎麼玩

1. 兩人各自打開網頁，選同一個案件，一人當「證詞組」，一人當「鑑識組」。
2. 只能用說的描述自己看到的文件，不要截圖。
3. 照片類證物可以點開放大，有些線索要放大才看得到。
4. 卷宗裡的時間可以點一下，加入「線索板」的時間軸。
5. 每章算出一道密碼才能前進。連續錯三次要冷卻一分鐘。
6. 到「偵訊」把文件出示給關係人。問出新證詞後，紀錄下方會顯示四位數代碼，念給夥伴在「偵訊」頁上方輸入。
7. 結案報告九題全對後，還有最後一場對質。

一個人也可以玩：選「單人模式」。進度存在各自手機的瀏覽器裡。

## 放上 GitHub Pages

1. 把 `index.html`、`.nojekyll`、`README.md` 放在 repository 根目錄。
2. Settings → Pages → Deploy from a branch，Branch 選 `main`、資料夾選 `/ (root)`。
3. 網址是 `https://<帳號>.github.io/<repository 名稱>/`。

`index.html` 是單一檔案，不需要其他相依檔。

GitHub 版沒有即時同步，也沒有房間代碼。偵訊紀錄用四位數代碼交換，密碼和結案報告兩人各自輸入。

## 劇透警告

`src/` 資料夾裡有每個案件的完整答案。公開的 repository 如果不想讓玩家翻到答案，就不要上傳 `src/`。

## 修改內容

需要 Node.js，不需要安裝套件。

```
node src/build.js
```

會重新產生根目錄的 `index.html`。

| 檔案 | 內容 |
|---|---|
| `src/template.html` | 介面與遊戲引擎 |
| `src/case1.js`、`case2.js`、`case3.js` | 各案件的文件、密碼、偵訊、對質、結局 |
| `src/imgs.js` | 證物插圖（SVG） |
| `src/helpers.js` | 文件排版用的小函式 |
| `src/build.js` | 把以上合成 `index.html` |
